//: THE CHRONICLE, ON SCREEN

Evidence you can
attach to a ticket

Intermittent Wi-Fi is hard to prove after the link recovers. RadioChron Desktop records baselines, compares observations, maps nearby radios, explains channel pressure, and keeps diagnostic evidence local.

//: 01 — REAL APP, SYNTHETIC DATA

Radio evidence without exposing a network

These images are captured by Electron itself in a fixture mode that never reads the host. SSIDs are invented, MAC addresses are locally administered, and addresses use documentation-only ranges.

//: 02 — WHAT IT DOES

Capabilities

Baseline runs

Capture a timed baseline of the connection and environment, retain it locally and compare runs.

Evidence timeline

Reconnect and environment observations become a support-ready chronology, not just a snapshot.

AP inventory

SSID/BSSID, dBm, band, channel, advertised security, BSS information elements and first/last seen history.

Relative RF view

Deterministic signal-based layout with collision correction. It is visualization, not ranging or geolocation.

Channel pressure

Explain crowded channels using live APs, signal mix, overlap and advertised BSS load.

Local-first

No telemetry, accounts, cookies or cloud dependency. Export only when the operator asks.
//: 03 — SEPARATE REPOSITORIES, ONE CORE

Electron consumes the Node library

The desktop app imports radiochron-js like any other Node application. That npm library packages a small native Node adapter linked to the radiochron Rust IoT core.

radiochron-electron (Electron + React)
        | import "radiochron"
        v
radiochron-js (Node/npm API)
        | packaged radiochron-node-bridge
        v
radiochron (Rust IoT core)
        |-- Windows Native WLAN
        |-- Linux nl80211
        `-- macOS CoreWLAN

Each component has its own repository and release lifecycle. Other Node services can use radiochron-js without Electron.

//: 04 — INSTALLERS

Built in CI, not released yet

The repository builds an assisted Windows NSIS installer plus DMG and ZIP artifacts for Intel Mac and Apple Silicon. They remain CI artifacts while signing, notarization and final release policy are unfinished.

$ git clone https://github.com/sergii-ziborov/radiochron-electron
$ cd radiochron-electron
$ npm ci
$ npm run check          # typecheck + 75 tests
$ npm run native:build
$ npm run dist:win -- --x64
$ npm run dist:mac -- --arm64
  • macOS uses CoreWLAN and requires Location Services to expose SSID/BSSID scan data.
  • Unsigned local artifacts are for testing; public Apple downloads require Developer ID signing and notarization.
  • Not a packet sniffer, geolocation product or offensive vulnerability scanner.
